# Soleil Grid Hub: consistency review (read-only)

Scope: `00-shared-context.md` read in full. `db/schema.sql` read in full. All 126 openapi operations and all 102 component schemas were extracted and compared programmatically. Docs 01 to 10 were grepped by topic. Citations use `file:line`, or `openapi:<Schema>` / `openapi:<operationId>`. "Schema" means `db/schema.sql`.

**Two structural findings sit behind many rows.**
- `db/schema.sql` (35 tables) is described as "canonical" (03:56) and "executed and tested". `openapi.yaml` is a separate vocabulary. Almost every status enum in the API differs from the schema's CHECK constraints.
- Docs 02, 03, 06, 07 and 09 each invent their own table, role and stream names. See C-04, C-08, C-17, C-19, C-24 and C-25.
